# 04 大筋と章構成

## 1. 大筋（あらすじ）

世界が終わるまで、あと七日。
白鷺総合病院707号室の無菌室から三年間出られない「私」に、看護師ミナセは一台の古い電話機を持ってくる。一年前に死んだ少女ミルの電話だ。ミナセは街にチラシを貼り、「真夜中の電話相談」を始めさせる。規則は三つ――最後まで聞くこと、名乗らないこと、五時には眠ること。

電話は鳴る。眠るのが怖い高校生レニィ。苦情を言いに来た洋館ホテルの主ネオ。夜中にひとりの五歳児ムニ。荷物を配り続けるバイク便のジンパチ。海賊ラジオのヒュウ。そして毎晩2:22、何も言わない誰か。

私は「つなぐ」ことを覚え、声だけの友達たちは互いに出会っていく。夜食会、しりとり、炭のオムレツ。
だが第三夜の明け方、「行ってきます」と薬を取りに出たミナセは帰らない。彼女はムニの母だった。
第四夜、橋に集まる群衆を救うため、ヒュウは「星は逸れる」と嘘をつくか、真実を語るかを選ぶ。安心したレニィは、眠ったまま起きなくなる――白眠。

第五夜。「おはよう、レニィ」で彼は目を覚まし、「別の夜」の夢を語る。みんなは明日の晩餐会を約束する。その一時間後、街は燃える。煙の前で足がすくむジンパチに、私は電話越しに「一緒に行く」と言えるか。燃える月見館から、ネオは祖父の肖像画を捨てられるか。
その明け方、地震で落ちた電話機から、ミルの手紙が出てくる。「出てくれなかった夜があっても、いいの」。

第六夜。地下通路でミナセが見つかる。ムニの「おかえり」の声が母を目覚めさせようとしている、その2:22――割り込み着信。崩れかけた天文台から、ゲルがかけてくる。どちらかの箱しか開けられない。
ミルの手紙を読み上げたとき、ゲルは初めて声を上げて泣き、ドームを降りる。そして最後の観測結果を告げる。白星は衝突しない。4:44、人類は眠ったまま終わる――。
最後にしたいことを話し合った夜明け前、私自身が白眠に落ちる。

第七夜。白い夢の中でミルが待っていた。「もう、誰の電話にも出なくていい」。遠くで電話が鳴る。私の名前を知っている人の声だけが、夢の底まで届く。
目を覚ませば、ガラスの向こうに声の主たちがいる。三年ぶりに部屋の外へ。屋上の白い夜明け、最後の朝ごはん。眠気に抗って、私たちは互いの名前を呼び続ける――。
