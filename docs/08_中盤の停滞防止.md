# 08 中盤の停滞防止

七夜×電話という形式は、放っておくと「毎晩誰かがかけてきて話を聞く」の繰り返しになる。以下の仕掛けで、中盤（第三夜〜第五夜）の単調さを防いでいる。

## 1. 形式そのものを毎夜変える

| 夜 | 電話の「形」 | 新しい遊び |
|---|---|---|
| 第一夜 | 1対1で受ける | 取るか取らないか（序章）、沈黙を待つ時限選択（第3話） |
| 第二夜 | 同時着信 | **どちらかしか取れない**（取らなかった方は留守録）／**こちらからかける**（自由通話A） |
| 第三夜 | 三者通話 | **つなぐ**（人と人を出会わせる）／**電波で名乗る**（一度に三人に届く） |
| 第四夜 | 主人公が指揮する | 外に出られない主人公が、他人を「足」にして動かす（迎え・捜索） |
| 第五夜 | 眠る人に電話をかける | **声で起こす**（呼びかけの言葉選び）／火事の中の遠隔誘導 |
| 第六夜 | 回線が足りない | 三者通話中の**割り込み**（2回線の物理制約が選択になる） |
| 第七夜 | 自分が呼ばれる | 役割の反転：六人が主人公を鳴らす |

## 2. 情報の出し方（謎の階段を必ず一段ずつ上る）
- 毎夜、**一つは答え、一つは新しい謎** を出す（03 進行表 §2）。
- 答えは必ず「次の謎」を連れてくる：
  - 無言電話の主＝ゲル（答え）→ なぜ2:22か（謎）
  - チラシの主＝ミナセ（答え）→ ミナセはどこへ（謎）
  - 白眠の起こし方（答え）→ ピーク後は届かない（謎：主人公は？）

## 3. 関係性を動かし続ける（仲良し固定にしない）
- 第三夜で全員の関係が温まった直後に、**第四夜で「嘘」を投げ込む**。嘘ルートではヒュウとジンパチが断絶し、ゲルは主人公の「知っていたか」を問う（主人公にも嘘をつく選択肢がある）。
- 真実ルートでも、鳴りやまない電話でレニィとゲルの電話を「取れない」＝関係の取りこぼしが起きる。
- 第五夜の火事は、ネオ×ジンパチ（反目→命を託す）、レニィ×ムニ（火の中の「ぎゅってしてる」）の関係を一気に深める。

## 4. 主人公自身の罪を中盤で掘る
- 第12話で「言えない」と飲み込んだ罪（ミルの最後の夜）を、第20話でゲルの告白が刺激し、第五夜章末の手紙が先回りして赦し、第23話で告白する。
- 「話を聞く側」の主人公が、中盤で「話せない側」でもあることが分かる → 読者の関心が主人公自身にも向く。

## 5. 選択の手応えを中盤で最大化する
- 第13話（ムニの預け先）で **第14話の日常がまったく別の場面** になる（読み聞かせ／毛布の砦）。
- 第15話（嘘／真実）で第16〜21話の展開が **別の物語** になる（花火と告発／鳴りやまない電話と少女）。
- 第17話は「何を言えば起きるか」をプレイヤーが推理する（第1話・第9話・第16話の情報の組み合わせ）。
- 第19話は、第7・11・14話で聞いた何気ない話が **命綱** になる（隣の屋上、裏階段、屋根裏）。

## 6. 日常を「次の喪失の担保」にする
- 事件と事件の間には必ず1〜3個の日常を置き、**その日常の中身を、直後の事件で奪う**：
  - 晩餐会の約束（第17話）→ 館が燃える（第19話）
  - しおバター（第1話〜）→ 「しおバター、全部、燃えちゃった」（第19話）
  - まかない「ママの分も」（第六夜）→ 2:22の選択でママの声が届かない（第23話）
  - 「おかえり」の練習（第12話）→ 言う相手が帰ってこない（第13話）→ 第22話で届く

## 7. 周回で中盤が変わる
- 2周目以降、第1話からレニィの台詞が変わり（「また会えたね」）、第17話の夢の話で「前の周回で起きたこと」をヒントとして語る。
- 同じ中盤でも「知っている読者」には、火事や2:22が「今度こそ」の緊張に変わる。
