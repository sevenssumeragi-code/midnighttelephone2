# 02 キャラクター設定

全員に **秘密・弱さ・恐れ・願望** を設定し、それぞれの「心残り」が物語上の事件と直結するように設計している。
口調は `data/characters.js` の `VOICE_RULES` で自動検査（`node tools/validate.js`）。

---

## レニィ（男子高校生）

| 項目 | 内容 |
|---|---|
| 外見 | 青い髪、青い目。寝癖 |
| 口調 | 一人称「僕」。「〜だよ」「〜だね」。まれに「〜だよぉ」「〜だねぇ」と語尾が伸びる。ジンパチ・ヒュウは呼び捨て |
| 立場 | 駅前のコンビニの上、5F角部屋にひとり暮らし。両親は遠い国で働いている |
| 性格 | ほわほわ天然。年中眠い。人懐っこく、子供に好かれる |
| **秘密** | 本人も気づいていないが、「いつもの眠気」に白眠の初期症状が混じっている。また、眠りの中で **別の夜（別の分岐）の夢** を見ている（第一夜から既視感として漏れている） |
| **弱さ** | 起きていられない。約束を寝過ごす |
| **恐れ** | 眠ったまま、誰にも起こされずに終わること |
| **願望** | 誰かと一緒に「いただきます」と朝ごはんを食べたい |
| 鍵 | 毎朝7時の国際電話「おはよう、レニィ」でだけ起きられた（3日前から不通）。→ 第五夜、主人公の「おはよう、レニィ」で目覚める |
| アーク | 「眠るのが怖い」→（嘘の放送で安心して眠る）→ 白眠 → 目覚める →「眠るのが怖いんじゃない。最後まで、みんなといたい」→ 最終夜、いちばん眠いはずの彼が最後まで起きている |

## ヒュウ（海賊ラジオのパーソナリティ）

| 項目 | 内容 |
|---|---|
| 外見 | 緑の髪、右目を前髪で隠す。瞳は赤 |
| 口調 | 一人称「僕」、常に敬語。レニィは呼び捨て、ジンパチは「ジンパチくん」。主人公は「あなた」「相談員さん」「{name}さん」 |
| 立場 | 港町の14階建てマンション屋上から、77.7MHz「ミッドナイト・ヒュウ」 |
| 性格 | ナルシストで気取り屋。「僕の美しさは声だけで十分」 |
| **秘密** | 元・舞台俳優。初主演の千秋楽で照明の吊り具が落ち、右目の視力を失った。部屋に鏡が一枚もない |
| **弱さ** | 醜いと思う自分を見せられない。嘘（演技）に逃げる |
| **恐れ** | 誰にも声が届かないこと／素顔を見られること |
| **願望** | 自分を救った深夜ラジオの声（「生きてるだけでいいんです」）に、自分もなること |
| 鍵 | 3年前、白鷺大橋で欄干に手をかけた夜の記憶 → 第四夜、同じ橋の群衆を救うため「白星は逸れる」と嘘をつくか、真実を語るかの分岐 |
| アーク | 仮面 → 嘘（または真実）→ 断罪（または街の目になる）→ 素顔（前髪を上げる）→ 最終放送 |

|---|---|

| 立場 | 白鷺急便。会社は2週間前に止まったが、倉庫の荷物を勝手に配り続けている |

## ムニ（5歳）

| 項目 | 内容 |
|---|---|
| 外見 | 青い髪（母ミナセ譲り）。※レニィとは無関係。作中でも「兄弟じゃないよ」と明言 |
| 口調 | 一人称「ぼく」。ひらがな主体。主人公を「でんわのひと」→名乗られれば「{name}ちゃん」。ネオを「ネオさま」 |
| 立場 | みなと団地に母と二人暮らし。父は1年前に白鷺病院で亡くなった |
| 性格 | 甘えん坊で寂しがり屋。「まつの、とくいだよ」 |
| **秘密** | 夜勤に出る母に「ママなんてきらい」と言ってしまい、母が泣いたのは自分のせいだと思っている |
| **弱さ** | 病院が嫌い（父を思い出す）。暗いのが怖い（白い夜で「ちょっとへいき」） |
| **恐れ** | ママが帰ってこないこと |
| **願望** | ママに「ごめんね」「だいすき」「おかえり」を言うこと |
| 鍵 | 冷蔵庫のメモ「やさしいひとがでます」＝チラシと同じ言葉 → 母はミナセ。第三夜の「おかえり」の練習が、第六夜にミナセを目覚めさせる言葉になる |

## ゲル（天文学者）※唯一の女性

| 項目 | 内容 |
|---|---|
| 外見 | 紫のセミロングボブ。白衣に煤けたジャケット |
| 口調 | 一人称「私」。「〜だ」「〜だな」「〜だろう」。**二人称は「君」**（「貴様」は使わない）。女性語尾（〜わ、〜のよ、〜かしら）は使わない |
| 立場 | 白鷺天文台の研究員。白星の追跡チーム。現在はドームにひとり |
| 性格 | 冷静、口が悪い、泣き声を殺すのがうまい |
| **秘密** | 1年前の2:22、妹ミルの最後の電話に出なかった（観測中だった）。葬式にも「忙しい」と嘘をついて行かなかった。以来毎晩2:22に、誰も出ない妹の番号を鳴らし続けていた |
| **弱さ** | 星（仕事）を言い訳に、人と向き合うことから逃げる |
| **恐れ** | 取り返しがつかないこと／自分が妹を見ていなかったこと |
| **願望** | 妹に赦されたい／最後まで見届けたい（妹の代わりに） |
| 鍵 | 2年前、ミルが白星の影を最初に見つけていた（星図）。ミルの手紙「星ばっかり見てないで、たまには、前も見てね」 |
| アーク | 無言電話（ホラー）→「その部屋に、誰がいる」（敵意）→ 姉と判明 → 告白 → 手紙 →「前も見ろ、か」→ ドームを出る → 星に「ミル」と名付ける |

## ネオ（月見館の主）

| 項目 | 内容 |
|---|---|
| 外見 | 金髪ロングヘアー |
| 口調 | 一人称「私」、二人称「貴様」。「〜だ」「〜だな」「〜せよ」。高飛車・高圧的。敬語（です/ます）は使わない |
| 立場 | 坂の上の洋館ホテル「月見館」三代目。祖父に育てられた |
| 性格 | 尊大だが根は普通の、少し臆病でやさしい青年。**悪者ではない**（最初から最後まで） |
| **秘密** | 客も使用人もいない。祖父は3ヶ月前に死去。**口調は祖父の真似** ―― そう話していると、祖父がまだ館にいる気がするから |
| **弱さ** | 料理ができない（炭のオムレツ）。ひとりでは何もできないと思っている |
| **恐れ** | 自分が何者でもなくなること（祖父の館を失うこと） |
| **願望** | 祖父の「秋の晩餐会」をもう一度開くこと |
| 鍵 | 「火事の時は裏階段を使え」「屋根裏のかくれんぼ」→ 第五夜の月見館火災。祖父の口調の理由を知っていれば、炎の中の彼を説得できる |

## 関係性の変化（固定しない）

| ペア | 序盤 | 中盤 | 終盤 |
|---|---|---|---|
| レニィ×ジンパチ | 電話越しの夜食会で出会う。「ふにゃふにゃした奴」 | 親友。起きないレニィに「バカ野郎」と泣く | しおバターを一緒に食べる |
| ヒュウ×ジンパチ | ジンパチはラジオを「腹立つ」と言いつつ聴く | 【嘘】断絶「嘘つき野郎」／【真実】「やるじゃねえか」 | 【嘘】和解（前髪を上げる）or 断絶のまま／【真実】戦友 |
| ネオ×ジンパチ | （つなげば）最悪の第一声。祖父の注文品を届ける | 火事で命を託す | 車の運転をめぐる漫才 |
| ネオ×ムニ | （預ければ）「ネオさま」 | 屋根裏のかくれんぼ／童話の続き | 卵を割る |
| レニィ×ムニ | （預ければ）毛布の砦、おそろいの髪 | 火の中の「ぎゅってしてる」 | お兄ちゃん役 |
| ゲル×ヒュウ | 【嘘】「星の嘘をついた」と告発 | ゲル「私も嘘つきだ」 | 「嘘つき同士だな」 |
