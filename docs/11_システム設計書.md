# 11 システム設計書

## 1. 全体構成

```
index.html
 ├─ data/*.js         … window.CHARACTERS / VOICE_RULES / CG_LIST / ENDINGS / MEMO / MEMO_CATS
 ├─ js/assets.js      … window.ASSETS（背景・立ち絵パス・BGM・SE・UI）
 ├─ scenario/*.js     … window.SCENARIO.push({id, text})  ※ファイル名順に連結
 ├─ js/compiler.js    … シナリオDSL → 命令列（ブラウザ/Node共通）
 ├─ js/engine.js      … VM（DOM非依存）。hostインターフェース経由で表示を依頼
 ├─ js/audio.js       … BGM（クロスフェード）/ SE
 ├─ js/ui.js          … hostの実装、メニュー群（セーブ・ロード・ログ・設定・ギャラリー・END・メモ・サウンド）
 └─ js/main.js        … 起動、画面遷移、入力
tools/validate.js      … Nodeでコンパイル＋静的検査＋ランダム周回＋ゴールデンパス
```

- **ビルド不要**、`file://` で動作（fetchを使わず、シナリオはJSの文字列として読み込む）。
- VMはDOMに依存しないため、Node上で数千周の自動プレイが可能（検証ツールが利用）。

## 2. シナリオDSL

ファイル形式：
```js
window.SCENARIO = window.SCENARIO || [];
window.SCENARIO.push({ id: '03_night3', text: String.raw`
 ...本文...
`});
```
- 本文中でバッククォート（`）と `${` は使用禁止。
- 1行＝1命令。空行は無視。`//` で始まる行はコメント。

### 2-1. 行の種類
| 書式 | 意味 |
|---|---|
| `*ラベル名` | ラベル（全ファイル通して一意） |
| `名前「台詞」` | 台詞。名前は16文字以内、空白・「」・記号不可。`{name}「…」`で主人公の台詞 |
| それ以外 | 地の文（`（心の声）` も地の文扱い） |
| `@コマンド 引数` | コマンド |
| `{name}` | 主人公名に置換（台詞・地の文・選択肢・名前欄） |

### 2-2. コマンド一覧
| コマンド | 書式 | 説明 |
|---|---|---|
| chapter | `@chapter <id> <タイトル>` | 章タイトルカード（クリック待ち）＋オートセーブ |
| episode | `@episode <タイトル>` | 話タイトル（1.8秒で自動送り） |
| center | `@center <文>` | 黒背景中央の独白（クリック待ち） |
| clock | `@clock HH:MM` | 電話パネルの時計 |
| bg | `@bg <id>` | 背景（CGは消える） |
| cg / cgoff | `@cg <id>` / `@cgoff` | イベントCG表示（グローバルに解放記録） |
| portrait | `@portrait <char> [表情]` / `@portrait none` | 通話相手の「想像の姿」 |
| line | `@line <1\|2> <ring\|talk\|hold\|off> [表示名]` | 電話パネルの回線状態。ringで着信音 |
| conf | `@conf on\|off` | 三者通話ランプ |
| hangup | `@hangup` | 全回線オフ・立ち絵消去・切断音 |
| bgm / se | `@bgm <id>\|stop` / `@se <id>` | 音 |
| effect | `@effect flash\|white\|shake` | 画面効果 |
| wait | `@wait <ms>` | 待機 |
| goto | `@goto <label>` | ジャンプ |
| gosub / return | `@gosub <label>` / `@return` | サブルーチン |
| if / elif / else / endif | `@if <式>` … | 条件ブロック（入れ子可） |
| choice / endchoice | 下記 | 選択肢 |
| set | `@set VAR = 式` / `+=` / `-=` | 変数 |
| aff | `@aff <char> +n` | 好感度（0〜100にクランプ） |
| kokoro | `@kokoro +n` | こころ（0〜10） |
| flag / unflag | `@flag F_XXX` | 真偽フラグ |
| gflag | `@gflag G_XXX` | 周回フラグ（グローバル保存） |
| memo | `@memo <id>` | 相談メモ解放 |
| input_name | `@input_name` | 名前入力 |
| set_top | `@set_top VAR a=式 b=式 …` | 式が真の候補から好感度最大のキャラIDを代入（同値は記述順） |
| ending | `@ending <ID>` | エンディング到達（G_END_ID、G_CLEAR_ONCE を立てる） |
| checkpoint | `@checkpoint` | オートセーブ |

### 2-3. 選択肢
```
@choice [timed=ミリ秒 default=ラベル] [style=phone]
- 選択肢の文 -> ラベル
- 条件付きの選択肢 -> ラベル if 式
@endchoice
```
- `timed`：時限選択。時間切れで `default` へ（沈黙＝選択、の表現）。
- `style=phone`：電話ボタン風の見た目（同時着信など）。
- 条件を満たす選択肢が0個になるとエラー（検証ツールで検出）。

### 2-4. 式
- 演算子：`&& || ! == != >= <= > < + -`、括弧
- リテラル：数値、`"文字列"`、`true` `false`
- 識別子：変数名（`aff.reny` のようにドットを含められる）。未定義は `false`。`G_` で始まる名前はグローバルフラグ
- 関数：`count(式, 式, …)`（真の個数）、`min(…)`、`max(…)`
- 例：`@set W = count(F_NAME_RENY && RENY_STATE == "AWAKE", F_NAME_HYU, F_NAME_JIN)`

## 3. VM（js/engine.js）

### 3-1. 状態
```js
state = {
  pc,                 // 命令インデックス
  vars: { name, kokoro, 'aff.reny', …, F_xxx, ROUTE, … },
  stack: [],          // gosub の戻り先
  visual: { bg, cg, portrait, portraitExpr, lines:{1:{state,label},2:{…}}, conf, clock, chapter, episode, bgm },
  lastText            // セーブ画面の抜粋
}
globals = { flags:{G_*}, cg:{}, endings:{}, memo:{}, read:{ "file:line":1 } }
```

### 3-2. hostインターフェース（UIが実装）
| メソッド | 呼ばれるとき | UIの責務 |
|---|---|---|
| text(speaker, text, meta) | 台詞・地の文 | 表示し、クリックで `vm.advance()` |
| choice(options, timed, def) | 選択肢 | 表示し、`vm.choose(index)` |
| inputName(def) | 名前入力 | 入力後 `vm.setName(str)` |
| title(kind, text) | chapter/episode/center | 表示後 `vm.advance()` |
| wait(ms) | @wait | 時間後 `vm.advance()` |
| visual(state) | 見た目の変化 | 背景・CG・立ち絵・電話パネル再描画 |
| sound(kind, id) | bgm/se | 再生 |
| effect(name) | 画面効果 | 演出 |
| ending(id) | @ending | エンディング画面 |
| saveGlobals() / autosave() | 解放・章開始 | localStorage保存 |
| affChanged / memoUnlocked | 変化時 | トースト表示（任意） |

### 3-3. セーブ形式
- `snapshot()`：現在の命令位置を「直前のラベル名＋オフセット」で保存（シナリオ修正に比較的強い）。vars・visual・stack・時刻・抜粋を含む。
- localStorageキー：`mt_save_1`〜`mt_save_18`、`mt_save_auto`（章開始時）、`mt_save_quick`、`mt_globals`、`mt_settings`
- **注意**：ラベルより前の行を追加・削除すると、そのラベル配下の既存セーブ位置がずれる。リリース後の修正はラベル直後ではなく、新ラベルを切って追記する運用を推奨。

### 3-4. 既読管理
- `globals.read["ファイルID:行番号"]`。既読テキストは色が変わり、スキップ対象になる（設定で未読もスキップ可）。

## 4. UI機能
| 機能 | 操作 |
|---|---|
| テキスト送り | クリック / Enter / Space / → |
| スキップ | SKIPボタン / Ctrl長押し（既読のみ。設定で未読も） |
| オート | AUTOボタン / A |
| バックログ | LOGボタン / L / ホイール上 / PageUp |
| ウィンドウ非表示 | HIDEボタン / H / 右クリック |
| セーブ／ロード | 18枠＋オート＋クイック。F5/F9 でクイック |
| 選択肢 | クリック / 数字キー1〜9 |
| 時限選択 | 赤いバーが減る。時間切れで既定の選択 |
| 相談メモ | 謎・人物の手帳（カテゴリ別、周回をまたいで蓄積） |
| ギャラリー | 章ごとのCG一覧、回収率表示 |
| エンディングリスト | 未到達はヒント表示 |
| サウンド | BGM試聴（素材確認用） |
| 設定 | 文字速度、オート待ち、BGM/SE音量、文字サイズ、未読スキップ、好感度変化の表示 |
| デバッグ | `?debug=1`：変数一覧、ラベルジャンプ、全CG/全END解放、グローバル初期化 |

画面は1280×720固定レイアウトをウィンドウに合わせて拡縮（スマホ横持ち可、タップで進行）。

## 5. 素材の差し替え
- 背景：`ASSETS.bg[id] = { path, color }`。画像がなければ `color` の単色＋ID表示。
- 立ち絵：`ASSETS.charaPath = 'assets/chara/{char}_{expr}.png'`。なければキャラ色のシルエット。
- CG：`data/cg.js` の `file`。なければ「ID・題・構図説明」を描いたプレースホルダー。
- BGM/SE：`ASSETS.bgm[id]` / `ASSETS.se[id]`。なければ無音で続行。
- 詳細仕様：`13_Codex向け素材実装指示書.md`

## 6. 検証ツール（tools/validate.js）
| 検査 | 内容 |
|---|---|
| コンパイル | ラベル重複、if/endif対応、選択肢書式 |
| 参照 | ジャンプ先、CG、エンディング、メモ、立ち絵キャラ・表情、背景/BGM/SE ID |
| フラグ | 条件で使うのにどこでも立たない変数（エラー）／立つのに使われないフラグ（警告） |
| 口調 | `VOICE_RULES`：一人称・二人称・呼称・禁止語（例：ゲルの「貴様」、ネオの敬語、ヒュウの「ジンパチ」にくん無し） |
| ランダム周回 | 既定6000周（40周ごとに周回フラグをリセット）。実行時エラー、無限ループ、未到達ラベル／エンディング |
| ゴールデンパス | `tools/golden_paths.js` の方針で全14エンディング（TRUEは2ルート）に確実に到達するか |
| レポート | `--report` で `docs/generated/validation_report.md`・`flags_reference.md` |

コマンド：
```
node tools/validate.js               # 検査（問題があれば終了コード1）
node tools/validate.js --runs 20000  # 周回数を増やす
node tools/validate.js --report      # レポート出力
```
