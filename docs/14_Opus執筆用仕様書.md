# 14 Opus執筆用仕様書

後からOpus（または他の執筆AI・ライター）にシナリオの加筆・推敲・拡張を依頼するための仕様書。
**この文書と docs/01〜10 を正典（カノン）とし、矛盾する加筆は行わない。**

---

## 1. あなたの役割と優先順位

あなたはAAA級ゲームシナリオライターとして、既存の『ミッドナイト・テレフォン』を加筆・推敲する。
優先順位は次の通り（上ほど優先）。

1. **面白さ**：続きが気になる。危機→安心→再危機→反転。予想外だが後から納得できる。
2. **キャラクターを好きになる時間**：重要イベントの前には必ず日常（食事・遊び・笑い・秘密を話す・喧嘩と仲直り）を置く。「この時間が永遠に続いてほしい」と思わせる。
3. **感情曲線**：読者が安心した瞬間に絶望を入れる（07 参照）。
4. **無矛盾**：世界設定・時系列・口調・フラグ条件を壊さない（§3）。
5. **伏線と回収**：新しい伏線を置いたら必ず回収先を 06 に追記する。

禁止：ご都合主義／突然の性格変更／理由のない裏切り／意味のない死亡／単調な繰り返し／伏線未回収／キャラ崩壊。
追加禁止設定：**レニィとムニは兄弟ではない・同一人物でもない**。**ネオは悪者ではない**（最初から最後まで普通の人）。

## 2. 正典の要点（必読の要約）

- 世界：白星は第八日の4:44に最接近（衝突ではなく通過。磁場で全員が眠り、その後潮汐で終わる）。白眠のルールは 01 §4。
- 主人公：707号室から出られない。名前はプレイヤー入力（`{name}`）。性別・年齢・容姿は書かない。地の文の一人称は「私」。台詞は少なく、選択肢が主人公の声。
- 規則：一、最後まで聞く。二、名乗らない。三、5時に眠る。
- 核心の秘密：主人公もゲルも、ミルの最後の電話（2:22）に出なかった。
- エンディング判定：`W`（名前を知っていて起きている人数）とTRUE条件（05 §5）。

## 3. 絶対に壊してはいけない不変条件（インバリアント）

| 分類 | 不変条件 |
|---|---|
| 時系列 | 各夜は22:00〜5:00。第七夜のみDay7〜Day8 4:44。白星の見かけの大きさは 12 §1 の順に大きくなる |
| 名前 | 主人公の名前を呼べるのは、その人に名乗ったとき（`F_NAME_XXX`）だけ。必ず `@if F_NAME_XXX … @else … @endif` で書き分ける（ゲルは `F_NAME_GEL`、電波名乗りは3人に同時に届く） |
| 呼称 | 02 の呼称表に従う。ヒュウは「ジンパチくん」「レニィ」、レニィは「ジンパチ」「ヒュウ」（敬称なし） |
| 口調 | 02 と `data/characters.js` の VOICE_RULES。特に：ゲルは「貴様」禁止・女性語尾禁止・二人称は「君」／ネオは敬語禁止・二人称「貴様」／ヒュウは常に敬語／ムニはひらがな主体 |
| 情報の開示順 | ゲル＝ミルの姉は第12話より前に確定させない（示唆はよい）／ミナセ＝ムニの母は第13話で確定／白星が衝突しないことは第23話でゲルが明かすまで誰も知らない／主人公の罪は第23話（または第25話）まで口に出さない |
| 生死 | 途中死亡はBAD02/03/04のみ。それ以外のルートで主要人物を死なせない |
| 物理 | 電話機は2回線。三者通話は2回線を両方使う。主人公は第28話まで部屋から出ない |
| ラベル | 既存ラベル名は変更しない（セーブデータ互換・ゴールデンパス互換）。新規ラベルは `ep17_xxx` のように所属話を接頭辞にする |
| 選択肢 | 「正解一つ・不正解二つ」にしない。どの選択肢にも固有の返答と、何かしらの情報・感情を持たせる |

## 4. 文体ガイド

- **1行＝1クリック**。地の文は1行40字前後、長くても60字。台詞も1行1文〜2文。
- **会話だけで進めない**。3〜6行に1度は情景（受話器越しの生活音、窓の外の白星、空気清浄機の唸り、ガラスの冷たさ）か心理描写を挟む。
- **説明ではなく出来事で見せる**。「ネオは孤独だった」ではなく「焦げたフライパンを置く音が、がらん、とやけに大きく響いた」。
- 電話ならではの描写：相手の姿は見えない。**音と間**で描く（息を呑む、柱時計、エンジン音、すする音、沈黙の長さ）。
- 引き（ヒキ）：各話の最後、各夜の章末は「続きが気になる一文」で止める。
- 章に一度は感情が大きく動く場面（友情・喪失・すれ違い・後悔・優しさ・救い）。
- 主人公の独白は（ ）で囲むか地の文。台詞は `{name}「……」`。
- 擬音はひらがな／カタカナ混在可。記号は「……」「――」。感嘆符の多用は避ける。

## 5. DSLの書き方（抜粋。完全版は 11 §2）

### 5-1. 着信〜通話〜切断の定型
```
@clock 01:42
@line 1 ring 月見館
@se phone_ring
（地の文：鳴り方・液晶の表示・主人公の反応）
@se phone_pickup
@line 1 talk 月見館
@portrait neo normal
ネオ「……私だ」
…
@hangup
```

### 5-2. 同時着信（シュレディンガーの選択）
```
@line 1 ring レニィ
@line 2 ring 非通知
@se phone_ring
@choice style=phone
- 一番の回線（レニィ）に出る -> ep07_reny
- 二番の回線（非通知）に出る -> ep07_hyu
@endchoice
```
取らなかった側は留守録（`@se beep` → `留守番電話「一件の、メッセージが、あります」`）で後から一部を開けるか、永遠に閉じたままにする。

### 5-3. 三者通話
```
@se phone_dial
@line 2 talk ジンパチ
@se button
@conf on
…
@hangup
@conf off
```

### 5-4. 名前の出し分け（必須パターン）
```
@if F_NAME_MUNI
ムニ「{name}ちゃん！」
@else
ムニ「でんわのひと！」
@endif
```

### 5-5. 時限選択（沈黙＝選択）
```
@choice timed=12000 default=ep03_wait
- 「もしもし？」 -> ep03_a
- 黙って、待つ -> ep03_wait
@endchoice
```

### 5-6. 好感度・フラグ・メモ・CG
```
@aff reny +10
@kokoro +1
@flag F_RENY_ROOF
@memo reny_roof        ← data/memo.js に項目を追加すること
@cg CG16b              ← data/cg.js に項目を追加すること
```

## 6. 拡張してよい枠（加筆の推奨箇所）

| 枠 | 場所 | 指示 |
|---|---|---|
| 自由通話C | 第四夜 1:00前後（放送の直後）／第五夜 3:30（火事の後） | 自由通話A/Bと同じ形式（`n2_free` 参照）。各キャラ1本、1本あたり20〜40行。好感度+5〜10、周回で見たくなる小さな秘密を1つ |
| 見知らぬ人の電話 | 第16話（真実ルートの洪水） | 1本10〜20行のショートショートを追加。主人公のこころ+1。本筋のフラグは立てない |
| 昼パートの探索 | day1〜day5 | 選択肢を1つ追加する場合、新しい情報は既存の伏線表のどれかに接続すること |
| 第27話の二人選択 | 全キャラ | 各キャラ15〜30行まで拡張可。ルートによる台詞差分（和解・負傷・名乗り）を必ず入れる |
| ペアの「つなぐ」イベント | 第三夜以降の自由通話 | 未実装のペア（ゲル×ムニ、ヒュウ×レニィ、ゲル×ネオ等）。関係性の変化表（02）を更新 |
| 差分CG | 12 §3 | シナリオ側で `@if` により別IDを出し分け |

**やってはいけない拡張**：新しい死亡・新しい大分岐・エンディング条件の変更・既存の真相の変更（これらは企画判断が必要）。

## 7. 作業手順とチェックリスト

1. 加筆箇所の前後（最低でも該当する夜の全体）を読み、フラグの状態を 05 と `docs/generated/flags_reference.md` で確認する
2. 書く（§4 文体、§5 DSL）
3. 新規の `@memo` `@cg` を `data/memo.js` `data/cg.js` に登録する
4. `node tools/validate.js` を実行し、**問題0件・ゴールデンパス全成功** を確認する（口調違反もここで検出される）
5. 新しいラベルで選択肢の分岐を増やした場合、`tools/golden_paths.js` の方針が壊れていないか確認する
6. 伏線を置いたら 06、フラグを足したら 05、話の中身を変えたら 10 を更新する
7. `node tools/validate.js --report` でレポートを再生成する

提出前チェック：
- [ ] 名前を呼ぶ行はすべて `F_NAME_XXX` で分岐しているか
- [ ] 呼称・一人称・二人称・語尾は呼称表とVOICE_RULESに合っているか
- [ ] 時刻（@clock）は前後の話と矛盾しないか（同じ夜の中で時間が戻っていないか）
- [ ] その時点で主人公・キャラが「知らないはずのこと」を話していないか
- [ ] 日常→事件の順で、事件の直前に「失うもの」を描いたか
- [ ] 各選択肢に固有の返答があるか
- [ ] 引きのある終わり方か
