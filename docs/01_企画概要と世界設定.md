# 01 企画概要と世界設定

## 1. コンセプト

> **取らなかった電話の向こうは、箱の中の猫。**
> 観測（＝話を聞くこと）が、人の生死と心を決める。

『シュレディンガーズコール』へのオマージュ。プレイヤーは **外に出られない電話相談員** として、世界が終わるまでの七夜、六人の声だけを頼りに彼らの心残りに寄り添う。

主人公ができることは四つだけ。

| 行為 | ゲーム上の意味 |
|---|---|
| **聴く** | 話を最後まで聞く。沈黙を待つ。好感度・情報（フラグ）の獲得 |
| **話す** | 言葉を選ぶ。相手の心を動かす／傷つける |
| **つなぐ** | 三者通話で、外にいる人同士を結ぶ（動けない主人公の唯一の「足」） |
| **名乗る** | 規則を破り、自分の名前を渡す。＝情が移る。最終夜、名前を知る人の声だけが主人公を呼び戻せる |

そして、**同時に鳴る二本の電話**。片方を取れば、もう片方で何が起きたかは「箱の中」になる（留守録で後から開けられることもあれば、開けられないこともある）。

## 2. テーマ

- **「出られなかった電話」への赦し** ―― 主人公もゲルも、死んだ少女ミルの最後の電話に出なかった。ゲームの全体が「今度は、出る」ための七夜。
- **名前を渡すこと＝情が移ること** ―― ミナセの規則「名乗らないこと（辛くなるから）」。名乗れば別れは辛くなる。それでも、名前を知っている人の声だけが、眠りの底から人を呼び戻せる。
- **鳴らすことに意味がある** ―― ミルの手紙「鳴らせるだけで、じゅうぶん、さみしくなかった」。最終夜、今度は六人が主人公の電話を鳴らす側に回る（役割の反転）。

## 4. 世界の終わり ―― 白星（しらほし）と白眠（はくみん）

| 時期 | 出来事 |
|---|---|
| 2年前の冬 | 入院中のミル（当時13歳）が、手製の星図に「星がときどき消える。なにかが前を通ってる？」と記録。姉ゲルは「気のせいだ」と笑った |
| 1年前 | ミル死去（2:22に姉へ、続けて隣室の主人公へ電話。どちらも出なかった） |
| 1年以内（公式） | 白星の正式発見。最初は暗く見えにくい天体だった |
| 3ヶ月前 | 肉眼で見え始める。ネオの祖父死去。ミナセが主人公のためにマフラーを注文 |
| 40日ほど前 | 政府発表：「7日目の夜明け、午前4時44分に到達（衝突）」 |
| 第一夜（Day1） | ミナセが電話相談を始める。4:44、空が白く光り、白眠の初観測 |
| 第四夜〜 | 白眠者急増。第五夜の昼には市内の6割超 |
| 第六夜 2:40 | 潮汐のピーク。天文台ドーム崩落。白眠が深化（ひとつの声では起こせなくなる） |
| 第七夜 4:44 | 最接近。人類は全員眠りに落ち、世界は終わる |

### 白眠のルール（作中で段階的に開示）
1. 白星の磁場の先端が触れると、人はその場で眠る。呼吸・脈は正常、代謝が冬眠のように落ちるため何日眠っても弱らない（第一夜昼・ミナセ）
2. 揺すっても呼んでも起きない（第一夜・第五夜）
3. **眠る人は夢の中で「何かを待っている」。待っていたものが届けば目を覚ます**（第四夜ゲルの仮説／第五夜レニィで実証）
4. 2:40のピーク以降は白眠が深くなり、**ひとつの声では届かない**。多くの「自分の名前を呼ぶ声」が必要（第六夜ゲル／第七夜）
5. 白眠の夢の中では「別の夜（＝別の分岐）」が見える（第一夜の既視感 → 第五夜レニィの夢 → 周回ヒント）

### 最終の真相（第六夜・ゲルの最後の観測）
- 白星は **衝突しない**。月より近くをかすめて通る（それでも潮汐で世界は終わる）
- 最接近の4:44、磁場が地球全体を包み、**全員が眠ったまま終わる**。白眠は前触れだった
- → ヒュウの「逸れます」という嘘は、**半分だけ本当だった**（皮肉な伏線回収）
- → 最終夜の目的が「生き延びる」から「**最後まで、一緒に起きている**」へ反転する

## 5. 主人公

- 名前：プレイヤー入力（初期値「ヨル」）。性別・年齢は明示しない。一人称（地の文）は「私」
- 白鷺総合病院707号室の長期入院患者。血液の病気で、3年間無菌室から出ていない
- 3年前は隣の706号室にいて、707のミルと毎晩内線で話していた。ミルの死後、707へ移った
- **秘密**：ミルの最後の夜、内線に出なかった（起きていたのに、長電話に疲れていた）。以来、電話の呼び出し音が怖い
- **弱さ**：自分からは何も差し出せない（名前も、罪の告白も）
- **恐れ**：誰の役にも立たないまま終わること／また電話に出られないこと
- **願望**：最後に誰かの役に立ちたい（→ミナセが相談窓口を作る）／外に出て、声の主たちの顔を見たい

## 6. トーンと文体

- 静かな夜の群像劇。ホラー／ミステリーの緊張と、日常の温かさを交互に置く
- 「説明」ではなく「出来事」で見せる。情景（白い夜、空気清浄機の唸り、受話器越しの生活音）を必ず添える
- 主人公は多弁にしない。選択肢が主人公の声。地の文で心理を描く
