# 12 スチル製作・回収指示書

イベントCG（スチル）53枚、立ち絵8人分の製作指示と、プレイヤーが全回収するための導線設計。
データの正は `data/cg.js`（この表は同ファイルから生成）。画像を指定パスに置けば即座に反映される。

## 1. 共通製作ルール

| 項目 | 指示 |
|---|---|
| 解像度 | 1920×1080（16:9）。PNG または WebP（拡張子を変える場合は `data/cg.js` の file を修正） |
| 主人公 | **顔を描かない**。手・背中・横倒しの視界・ガラスに映る輪郭のみ。性別を特定させない |
| 白星の大きさ（時系列の一貫性） | 第一夜＝月の半分 → 第二夜＝ひとまわり大きい → 第三夜＝月より大きい → 第四〜五夜＝月の数倍 → 第六夜＝空の1/4 → 第七夜＝空の全部 |
| 夜の色 | 白星の光で夜が「白く」なっていく。第一夜は濃紺、第四夜以降は牛乳を溶かしたような灰白色 |
| 電話の向こうの描写 | CGは「主人公の想像」ではなく「実際のその場」。ただし主人公視点の独白と矛盾する物（例：ネオの館の客）は描かない |
| 差分 | 下表「差分」の指示があるものは、同IDで差分ファイル（`_b` 等）を用意し、必要なら `data/cg.js` に追加IDを定義する |
| 伏線の描き込み | CG07の小箱「白鷺総合病院 7F」、CG05とCG01の丸文字は**同一筆跡**、CG20aの屋根裏の小窓、CG20bの隣のビルとの隙間は**必ず画面内に入れる** |
