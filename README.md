# ミッドナイト・テレフォン ―白い夜の相談室―

世界が終わるまでの七日間。外に出られない電話相談員の「あなた」のもとに、六人から電話がかかってくる。
『シュレディンガーズコール』へのオマージュとして、**「取らなかった電話の向こうは、箱の中の猫」**を中心に据えた、電話だけで人の心残りに寄り添うADVノベルゲームです。

- 起動：`index.html` をブラウザで開くだけ（ビルド不要・外部ライブラリなし・`file://` で動作）
- デバッグ：`index.html?debug=1`（変数表示・ラベルジャンプ・全CG/全END解放）
- 検証：`node tools/validate.js`（`--report` で `docs/generated/` にレポート出力）

| イベントCG | 53枚（製作指示つき：`data/cg.js` / `docs/12_スチル製作・回収指示書.md`） |
| 相談メモ | 約150項目（謎・伏線・人物の手帳。周回で埋まっていく） |
| システム | テキスト送り／時限選択肢／セーブ18枠＋オート＋クイック／バックログ／オート／既読スキップ／ギャラリー／エンディングリスト（ヒント付）／相談メモ／サウンド鑑賞／設定 |

## グラフィック・BGM（Codex担当）

素材は **`js/assets.js` と `data/cg.js` に記載のパスへ置くだけ**で自動的に反映されます。未配置の間は、エンジンがプレースホルダー（CGは構図説明つき）を描画するため、素材なしでも最初から最後まで遊べます。
仕様は `docs/13_Codex向け素材実装指示書.md` を参照。

## ディレクトリ

```
index.html            起動ファイル
css/style.css         見た目
js/compiler.js        シナリオDSL → 命令列（Node/ブラウザ共通）
js/engine.js          実行VM（DOM非依存。Nodeで自動周回テスト可能）
js/ui.js, js/main.js  画面・入力・メニュー
js/audio.js           BGM/SE
js/assets.js          素材マニフェスト（背景・BGM・SE・立ち絵パス）
data/                 キャラクター定義・口調ルール／CG一覧／エンディング一覧／相談メモ
scenario/             シナリオ本体（00_prologue 〜 08_endings）
tools/validate.js     検証ツール（整合性・口調・ランダム周回・ゴールデンパス）
tools/golden_paths.js 全エンディング到達ルート定義
docs/                 設計書一式
```
